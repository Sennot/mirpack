# Spout2 Clean Feed

Geode-мод для Geometry Dash на Windows. В окне игры он показывает хитбоксы и две прогнозируемые траектории, а через Spout2 отправляет в OBS чистый кадр уровня без этих оверлеев.

## Как это работает

- Мод создаёт один общий корневой узел для своих хитбоксов и траекторий.
- Обычный кадр Geometry Dash рисуется без корневого узла оверлеев.
- Перед настоящим `swapBuffers` чистый backbuffer копируется в GPU-текстуру и отправляется в Spout2.
- Сразу после отправки корневой узел хитбоксов и траекторий вручную дорисовывается только на экран игрока.
- В Spout попадает вся остальная сцена целиком: интерфейс уровня, индикаторы, пауза, меню паузы и редактор. Отдельного списка элементов интерфейса нет.
- Spout-хук выполняется после `absolllute.hackmega` / `absolllute.megahack`, поэтому отрисованный Mega Hack попадает в OBS до фактического обмена буферов.
- Sender активен только внутри `PlayLayer` или `LevelEditorLayer` и освобождается при выходе.

Spout2 SDK 2.007.017 собирается статически прямо в DLL мода. Отдельные `Spout.dll` или файлы SDK рядом с модом не нужны.

## OBS

1. Установите в OBS совместимый источник-приёмник Spout2.
2. Запустите уровень или редактор Geometry Dash.
3. Добавьте Spout2 Capture Source и выберите sender `Geometry Dash Clean Feed`.
4. При необходимости измените имя sender в настройках мода Geode.

OBS-плагин-приёмник не входит в мод: он устанавливается отдельно в OBS.

## Настройки

Можно отдельно включать хитбоксы и траекторию, выбирать цвета и толщину линий, прозрачность заливки хитбоксов, длину прогнозирования и частоту симуляции. Значение 240 TPS используется по умолчанию как хороший баланс точности и нагрузки.

По умолчанию `F3` переключает хитбоксы, а `F4` — траекторию. Оба бинда переназначаются в настройках мода Geode и срабатывают только внутри уровня или редактора.

## Сборка

После push или pull request workflow `.github/workflows/build.yml` собирает Win64 `.geode` и PDB и публикует их как GitHub Actions artifact.

Для локальной сборки нужны Visual Studio 2022, CMake, Ninja и Geode SDK:

```powershell
$env:GEODE_SDK = "C:\path\to\geode"
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build
```
